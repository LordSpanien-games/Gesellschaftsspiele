📖 Spielregeln – Das eine Wort

Grundregeln

Ein Spieler rät ein geheimes Wort. Alle anderen geben je einen Hinweis-Begriff ein.

  • Jeder gibt einen Hinweis ein und bestätigt mit OK.
  • Sind alle fertig, sehen alle Mitspieler (außer dem Ratenden) die Hinweise alphabetisch sortiert.
  • Duplikate oder ungültige Hinweise werden manuell markiert und gestrichen.
  • Der Ratende sieht nur die verbleibenden Hinweise.
  • Wird das Wort erraten → +1 Punkt.
  • Wird es nicht erraten → 0 Punkte, Karte verloren.

Gewinnbedingung

  • Normal: 50% der Begriffe erraten → Gruppe gewinnt
  • Leicht: 60% der Begriffe erraten → Gruppe gewinnt
  • Schwer: 70% der Begriffe erraten → Gruppe gewinnt

Sonderregeln für 3 Spieler

⚠️ Wird noch ergänzt.

Emote-Edition

  • Statt einem Wort dürfen 1–3 Emojis als Hinweis verwendet werden.
  • Kein Emoji das den Begriff direkt darstellt ist erlaubt.
  • Beispiel: Wort = "Sonne" → ☀️ wäre verboten, 😎🌴🏖️ wäre erlaubt.

Redewendungen & Filmtitel

  • Als Hinweis darf eine Redewendung oder ein Filmtitel verwendet werden.
  • Der Hinweis darf das gesuchte Wort nicht direkt enthalten.
