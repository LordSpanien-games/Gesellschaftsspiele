🎭 Cyrano – Spielanleitung

← Zurück zum Spiel

🎯 Ziel des Spiels

Du bist ein Poet und willst deine/en Angebetete/n mit einem Gedicht beeindrucken.

Schreibe die schönsten Gedichte und Reime und klettere als Erster auf die Turmspitze!

👥 Spieler

  • 4 – 9 Spieler
  • Alle im selben Raum, jeder mit eigenem Handy oder PC
  • Ein Spieler erstellt den Raum und ist Host

⚙️ Raumkonfiguration

  • Anzahl Runden / Etagen: Wie hoch ist der Turm? Standard: 4
  • Begriff-Modus: Wie wird der Begriff jeder Runde bestimmt?
  • Thema-Modus: Wie wird das Thema für die Session bestimmt?
  • Abstimmung: Wer steigt nach jeder Runde auf?

🏷️ Begriff-Modi

  • System: Das Spiel wählt automatisch einen zufälligen Begriff
  • Reihum: Jede Runde gibt ein anderer Spieler den Begriff vor
  • Alle gleichzeitig: Jeder schlägt verdeckt einen Begriff vor – das System wählt zufällig einen

🎨 Thema-Modi

Das Thema gilt für die gesamte Session und ändert sich nicht zwischen den Runden!

  • System: Das Spiel wählt automatisch ein zufälliges Thema
  • Reihum: Ein Spieler gibt das Thema für die ganze Session vor
  • Verdeckt: Jeder schlägt verdeckt ein Thema vor – das System wählt zufällig eines

📜 Spielablauf pro Runde

  1. Begriff: Ein Begriff wird angezeigt (je nach Modus)
  2. Schreiben: Jeder schreibt eine Strophe passend zu Thema und Begriff
  3. Abstimmung: Alle Strophen werden angezeigt – jeder wählt seine Favoritstrophe
  4. Auswertung: Der Turm wird aktualisiert
  5. Nächste Runde: Der Host startet die nächste Runde

🗳️ Abstimmungs-Modi

  • es gibt mindestens eine Stimme: Wer die meisten Stimmen bekommt steigt eine Etage auf
  • Alle enthalten sich – alle steigen auf: Es steigen dennoch alle auf.
  • Alle enthalten sich – niemand steigt auf: Niemand steigt auf

⚠️ Du kannst nicht für deine eigene Strophe stimmen!

🤐 Du kannst dich auch enthalten – deine Stimme zählt dann nicht.

🏰 Der Turm

  • Jeder Spieler startet auf Etage 0
  • Wer die meisten Stimmen bekommt steigt eine Etage hoch
  • Wer als Erster die Turmspitze erreicht gewinnt!

🏆 Spielende

  • Normal: Erster der die Turmspitze erreicht gewinnt
  • Vorzeitig: Der Host kann das Spiel jederzeit beenden
  • Gleichstand: Wer insgesamt die meisten Likes hat gewinnt

🐛 Debugmodus

Nur für Tests – erlaubt weniger als 4 Spieler. Wird vom Host beim Erstellen aktiviert.
